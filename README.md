## 国内延迟和三网路由：直连是直连，快是快不起来

直连没有问题，延迟高是地理决定的。国内三网 ping 阿什本平均在 220ms 上下，部分地区偶发轻微丢包，非高峰时段稳定性说得过去；作为对比，西海岸的洛杉矶、西雅图一般在 150–180ms。

路由细节是这样的：

- **电信去程**：163 骨干网对接 NTT，直连无绕路
- **联通/移动去程**：骨干网对接 GTT，传输稳定
- **回程**：电信走 NTT 到圣何塞再进电信骨干网；联通经 NTT+GTT 走 L3 线路回国；移动走 GTT 对接国内骨干网，个别地区略有绕行

三网来回基本都保持直连，没有离谱的绕路。换句话说，线路质量在这里算不上短板，物理距离才是。阿什本在美国东海岸，到国内比西海岸远了上千公里，这部分延迟任何优化都省不掉。
